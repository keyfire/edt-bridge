# Быстрый старт EDT-Bridge

EDT-Bridge предоставляет Claude Code и другим MCP-клиентам доступ к модели 1C:EDT.
Инструменты читают метаданные и BSL, проверяют запросы и обращаются к Синтакс-помощнику платформы.
Они также создают объекты и расширения, выполняют рефакторинг, собирают `.epf` и `.erf` и обновляют
информационные базы. Операции выполняет штатный движок EDT.

Мост состоит из двух частей:

- **плагин 1C:EDT** – jar в `dropins/`, который запускает MCP-сервер внутри EDT на
  `http://127.0.0.1:8770/mcp`;
- **обвязка `edt-bridge-mcp`** на Python устанавливается через pipx. Она предоставляет клиенту
  stdio MCP-сервер и передает запросы в EDT. Если EDT не запущена, обвязка запускает ее в режиме
  headless. Если jar плагина отсутствует, обвязка устанавливает его.

## Требования

- Установленная **1C:EDT**. Обвязка может запустить ее в режиме headless. Также можно открыть EDT
  с интерфейсом и проектом.
- **Python 3.10+** и **pipx**. Если pipx нет, смотрите ниже.
- Установленная **платформа 1С:Предприятие**, совместимая с версией проекта. Она нужна только для
  сборки `.epf` и `.erf` и для обновления информационных баз.

## Установка (обычная – через pipx)

```bash
pipx install edt-bridge-mcp
```

Если pipx нет:

```bash
python -m pip install --user pipx
python -m pipx ensurepath      # затем переоткрыть терминал
```

macOS: `brew install pipx && pipx ensurepath`.

## Подключение к Claude Code

```bash
claude mcp add edt-bridge -- edt-bridge-mcp --workspace "D:\\путь\\к\\workspace-EDT"
```

`--workspace` задает папку рабочей области EDT, содержащую `.metadata`. Если EDT не запущена,
обвязка запускает ее с этой рабочей областью в режиме headless. Если EDT с интерфейсом и плагином
уже открыта, обвязка подключается к ней.

Для применения изменений инструментами записи задать токен:

```bash
claude mcp add edt-bridge --env EDT_BRIDGE_TOKEN=<любая-строка> -- \
  edt-bridge-mcp --workspace "D:\\путь\\к\\workspace-EDT"
```

## Проверка

В сессии Claude Code запросить список проектов или справку по API. Запрос "Покажи открытые проекты
EDT" вызывает `edt_projects`, а запрос "найди в Синтакс-помощнике ТаблицаЗначений.Добавить" –
`edt_platform_help`. Первый вызов может занять несколько минут, пока обвязка запускает headless EDT
и загружает модель. После загрузки модели инструменты доступны для вызова.

Проверить сервер вручную, когда EDT запущена с интерфейсом или без него:

```bash
curl -s http://127.0.0.1:8770/status
```

По адресу `http://127.0.0.1:8770/` в браузере открывается страница состояния, и там же запускается
любой инструмент.

## Обновление

```bash
edt-bridge-mcp self-update             # обновить и jar плагина (GitHub Releases), и обвязку (PyPI)
edt-bridge-mcp self-update --jar-only  # только jar
```

При обновлении старые jar удаляются из `dropins/`: при наличии двух файлов EDT может загрузить
любой из них. Запущенная EDT использует прежний код до перезапуска.

## Установка вручную (без обвязки)

Для запуска плагина вручную скачать jar со
[страницы Releases](https://github.com/keyfire/edt-bridge/releases), поместить **один** файл в
`dropins/` EDT и перезапустить EDT. Сервер запустится на 8770 или на следующем свободном порту. Клиент можно
подключить напрямую по HTTP:
`{ "edt-bridge": { "type": "http", "url": "http://127.0.0.1:8770/mcp" } }`. Подробности приведены на
странице [Установка](https://docs.keyfire.ru/edt-bridge/ru/install/), сборка из исходников – на странице
[Сборка из исходников](https://docs.keyfire.ru/edt-bridge/ru/build/).

## Если что-то не так

- **Клиент не видит инструменты сразу после старта.** Обвязка запускает headless EDT в фоне. Список инструментов появится после загрузки модели и получения `tools/list_changed`.
- **"a GUI EDT is running".** Открыта EDT с интерфейсом, но без плагина, и обвязка ее не трогает:
  рабочую область держит она. jar обвязка все равно доставит в `dropins/`, так что перезапустите эту
  EDT, чтобы активировать мост, либо закройте ее.
- **Порт 8770 занят.** Плагин берет следующий свободный, а обвязка находит его перебором. Порт можно
  задать и явно, через `EDT_BRIDGE_PORT`.
- **Инструмент записи отказывает: "requires a configured token".** Задайте `EDT_BRIDGE_TOKEN`, как
  показано выше.
- **`edt_dump_external_object` не собирает.** Ему нужна установленная платформа 1С:Предприятие,
  совместимая с версией проекта.
